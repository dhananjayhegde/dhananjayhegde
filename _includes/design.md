# Design System Rules for 11ty Blog

## Color System (60-30-10 Rule)
- Base (60%): Cream (#FDFBF7)
- Secondary/Text (30%): Dark Slate (#1A1F2C)
- Accent (10% - Interactive Only): Vivid Rust (#D95D39)

## Spacing & Typography
- Scale: Fluid typography utilizing `clamp()`
- Spacing: Strict 8px grid system using CSS variables (`--space-1`, `--space-2`)

## Forbidden Layout Elements
- No bright neon gradients, no glassmorphism, no forced dark/light mode flashes.
